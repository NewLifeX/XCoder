NewLife.XCoder bundles code generation, network/API/serial debugging, regex, icon and crypto tools, plus industrial protocol and DBC viewers.

## Installation

```bash
dotnet add package NewLife.XCoder
```

## Quick start

```bash
dotnet run --project XCoder-CLI
```

## Key features

- Companion CLI, debugging and visualization tools
- Code generation and strongly typed APIs with less boilerplate
- Cross-platform: Windows, Linux, macOS and ARM64/LoongArch64
