NewLife.XCoder regroupe génération de code, débogage réseau/API/série, regex, icônes et cryptographie, ainsi que des visionneuses de protocoles industriels et DBC.

## Installation

```bash
dotnet add package NewLife.XCoder
```

## Démarrage rapide

```bash
dotnet run --project XCoder-CLI
```

## Fonctionnalités

- Outils CLI, de débogage et de visualisation
- Génération de code et API fortement typées, moins de code répétitif
- Multiplateforme : Windows, Linux, macOS et ARM64/LoongArch64
