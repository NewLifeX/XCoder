NewLife.XCoder reúne generación de código, depuración de red/API/serie, regex, iconos y criptografía, además de visores de protocolos industriales y DBC.

## Instalación

```bash
dotnet add package NewLife.XCoder
```

## Inicio rápido

```bash
dotnet run --project XCoder-CLI
```

## Características

- Herramientas CLI, de depuración y visualización
- Generación de código y API fuertemente tipadas con menos código repetitivo
- Multiplataforma: Windows, Linux, macOS y ARM64/LoongArch64
