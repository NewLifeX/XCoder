NewLife.XCoder는 코드 생성, 네트워크/API/시리얼 디버깅, 정규식, 아이콘, 암호화 도구와 산업 프로토콜/DBC 뷰어를 통합합니다.

## 설치

```bash
dotnet add package NewLife.XCoder
```

## 빠른 시작

```bash
dotnet run --project XCoder-CLI
```

## 주요 기능

- CLI, 디버깅, 시각화 도구 제공
- 코드 생성과 강력한 형식 API로 반복 코드 감소
- 크로스 플랫폼: Windows, Linux, macOS, ARM64/LoongArch64
