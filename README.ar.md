> قد تتأخر هذه الترجمة عن النسخة الصينية.

يجمع NewLife.XCoder أدوات توليد الكود وتصحيح الشبكة وAPI والمنفذ التسلسلي والتعبيرات النمطية والأيقونات والتشفير، مع عارضات بروتوكولات صناعية وDBC.

## التثبيت

```bash
dotnet add package NewLife.XCoder
```

## البدء السريع

```bash
dotnet run --project XCoder-CLI
```

## الميزات الرئيسية

- أدوات سطر أوامر وتصحيح ومرئيات مرافقة
- توليد الكود وواجهات قوية الأنواع مع تقليل الكود المتكرر
- متعدد المنصات: Windows وLinux وmacOS وARM64/LoongArch64
