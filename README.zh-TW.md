NewLife.XCoder（碼神）整合程式碼產生、網路偵錯、API 測試、序列埠、正規表示式、圖示與加解密等常用開發工具，並支援工業協定與 DBC 檢視。

## 安裝

```bash
dotnet add package NewLife.XCoder
```

## 快速開始

```bash
dotnet run --project XCoder-CLI
```

## 核心特性

- 配套命令列、偵錯與視覺化工具
- 程式碼產生與強型別 API，減少樣板程式碼
- 跨平台支援 Windows、Linux、macOS 與 ARM64/LoongArch64
