NewLife.XCoder reúne geração de código, depuração de rede/API/serial, regex, ícones e criptografia, além de visualizadores de protocolos industriais e DBC.

## Instalação

```bash
dotnet add package NewLife.XCoder
```

## Início rápido

```bash
dotnet run --project XCoder-CLI
```

## Recursos

- Ferramentas CLI, de depuração e visualização
- Geração de código e APIs fortemente tipadas com menos boilerplate
- Multiplataforma: Windows, Linux, macOS e ARM64/LoongArch64
