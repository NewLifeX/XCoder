NewLife.XCoder объединяет генерацию кода, отладку сети/API/COM, регулярные выражения, значки и криптографию, а также просмотр промышленных протоколов и DBC.

## Установка

```bash
dotnet add package NewLife.XCoder
```

## Быстрый старт

```bash
dotnet run --project XCoder-CLI
```

## Возможности

- CLI, отладка и инструменты визуализации
- Генерация кода и строго типизированные API без лишнего кода
- Кроссплатформенность: Windows, Linux, macOS, ARM64/LoongArch64
