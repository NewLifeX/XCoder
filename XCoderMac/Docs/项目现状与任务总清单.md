# XCoder Mac 项目现状与任务总清单

> **当前唯一的进度基线**｜2026-10-19｜XCoder **0.3.3**｜工程目录 `XCoderMac/`。
> 说明：代码已实现 ≠ 业务已验证 ≠ 生产可用。完成状态必须注明测试证据和适用范围。

## 一、当前项目底数

- **26 个工具入口、4 个原有分类**：开发与数据、网络与协议、设备与运维、效率工具。
- 不再有额外的「数据工具」侧栏或首页入口（该设计曾加入，**已撤回**）。XML 模型、模型管理、建表 SQL 和架构/查询功能均位于「开发与数据 → 数据建模 → 模型与数据库工具」。
- 技术基线：.NET 10、Avalonia 12.1.1、Apple Silicon；Mac 代码仅在 `XCoderMac/`，通过 ProjectReference 复用 `XCoderAv`，不改 Windows 上游。
- 可用本地 APP：`XCoderMac/dist/XCoder.app`；安装包：`XCoderMac/dist/XCoder-arm64.dmg`。签名为 **ad-hoc**，尚未 Apple Developer ID 签名或公证。
- Git 为 `master`，存在未提交的 Mac 工作区改动。**未获明确要求不提交、不推送**；用户配置、密码、生产数据不得进仓库。

**进度分级**：A＝界面/导航/控件可用；B＝指定的离线或模拟业务逻辑已验证；C＝Mac 上真实测试库、网络服务或设备全链路验证；D＝安全、权限、失败恢复、性能及正式分发均验收。

**结论：26/26 个工具有 A 级入口；部分工具有 B 级的局部验证；目前不能声称 26/26 已完成业务功能，更不能声称达到生产级 D。**

## 四、未完成清单与优先级

### P0 — 先治理高风险写操作与安全

- [ ] 数据同步：差异预览、确认源/目标、备份、逐表执行、失败恢复、日志、测试库验收。
- [ ] SQL/DDL：数据库最小权限、只读和写入隔离、各方言检查；SQL 字符串正则检测不是安全沙箱。模型迁移先独立测试库演练再考虑生产。
- [ ] 文件编码、正则批量替换、手机备份：原文件可能被覆盖/移动/删除；必须有预览、备份、确认、恢复机制。
- [ ] IP 设置、PLC/Modbus、I/O 写入：平台适配、授权、设备隔离测试和误操作保护。
- [ ] SSH.NET / Tmds.DBus 历史漏洞告警需**重新扫描确认是否仍适用**；Keychain 真实凭据与配置备份敏感数据检查。

### P1 — 常用功能真实联调

- [ ] MySQL、SQL Server、PostgreSQL、SQLite 测试库：连接、模型/表结构、代码生成、建表 SQL 和查询对照。
- [ ] RPC/TCP/UDP、API 发现、消息、MQTT、Redis：用本机模拟服务测试连接、收发、重连、断线和退出清理。
- [ ] 串口、Modbus TCP/RTU：模拟器→独立测试设备；测试串口权限、读写地址、超时。
- [ ] 通用宿主的事件、样式、后台任务及关闭释放；加密解密全算法回归。
- [ ] SQL 结果展示增强：结构化表格、分页、导出及大结果集性能（现在为文本输出）。

### P2 — 完整功能与正式发行

- [ ] 声卡默认设备切换、梅尔频谱算法、图像/GPS/地图/USB 细节与性能。
- [ ] CI、自动化模拟服务、异常路径与不同 macOS 版本测试。
- [ ] Apple Developer ID、notarization（公证）、安装/升级/回退验证。

**建议下一步顺序**：先做数据同步与 SQL 写操作安全边界 → 独立测试库验收数据建模与查询 → 网络/RPC/Redis 模拟测试 → 文件/设备高风险写入 → 公证发行。真实生产数据库或 PLC 不用于冒烟测试。
