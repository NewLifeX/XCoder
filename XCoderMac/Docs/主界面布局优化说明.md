# XCoderMac 主界面布局优化（2026-10-18）

## 修改范围

仅调整 `XCoderMac/MacShellWindow.axaml` 与 `MacShellWindow.axaml.cs` 的主页布局；主窗口单标签工作区及 26 个工具业务功能保持原样。

- **左侧栏**：主 Grid 左列从 254 调整为 **216** 逻辑像素；Logo 与文字缩小，适应窄侧栏。
- **导航选中项**：所有工具/快捷工具使用约束宽度的 Grid，菜单 Button `HorizontalAlignment=Stretch`；选中项通过 `sidebar-item.selected` 样式高亮。点击其他分类时只高亮当前分类，确保整个菜单行一致。
- **工具卡片**：取消固定 252px 卡片宽度，用 `UniformGrid` 均分实际可用宽度。根据卡片区宽度实时确定列数：≥940px 为 4 列，≥690px 为 3 列，≥460px 为 2 列，其余为 1 列。列数是 Avalonia `StyledProperty`，缩放自动通知 UI。
- **布局间距**：保留原有首页欢迎横幅、统计卡、配色、导航与工具功能，仅微调卡片高度为 154px。

## 实机验证

测试命令：

```bash
dotnet build XCoderMac/XCoderMac.csproj -c Debug --no-restore
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-home-layout
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-tabs
```

`--smoke-home-layout` 会对 1000/1320/1540 三个窗口宽度分别校验工具列数、左菜单宽度和工具卡片伸展情况，并更新 `Docs/软件界面/00-首页.png`。其他 26 张工具截图保持不变。

测试观察：1320 宽工具区 1047px / 4 列；1000 宽工具区 727px / 3 列；1540 宽工具区 1267px / 4 列；选中导航按钮宽度 191px。
