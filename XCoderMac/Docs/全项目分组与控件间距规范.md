# XCoderMac 全项目分组与控件间距统一排查（2026-10-20）

## 目的与范围

用户反馈：加密解密左侧红框内的 WrapPanel 按钮相互贴合；同时要求检查 **整个 XCoderMac 项目**的分组间距和控件间距，而非仅修改此页。

此次范围：
- 读取 README 和唯一进度清单；
- 静态核查 **XCoderAv/Views 26 份上游工具 XAML** 中的 GroupBorder、Grid、StackPanel、WrapPanel 及控件自定义 Margin；
- 核查 **XCoderMac/Views 原生 XAML** 的 panel/分组与流面板；原生页面大多已使用明确的 StackPanel.Spacing、Grid 列距或控件 Margin；
- 运行所有 26 个工具的启动冒烟；再分别检查旧工具的分组布局和加密解密两种宽度的流按钮实际位置。

## 排查发现

1. 旧窗口常用 GroupBorder 类，其 Margin.Bottom 多数只有 4~6，而分组内部 Grid/StackPanel 的 RowSpacing/Spacing 常为 0；部分内容依赖单个控件 Margin 撑开，不一致。
2. 加密解密上游 SecurityWindow 使用固定宽度 240 的左栏，WrapPanel 31 个固定宽度 110、Margin=3 的按钮，既容易贴合，也存在按钮字受宽度约束的问题。
3. 加密解密右侧原文/密码两块用了三行 Grid，其中第二行空置，控件落在第三行；标题、RadioButton、输入框没有真正统一的显式间距。
4. 消息调试的 WrapPanel 勾选项依赖左右 Margin=4，**缺少换行行距**；窗口缩小后会显得拥挤。
5. 已精细适配的 MQTT、API 发现、文件编码、消息调试和部分 Mac 原生页面都存在各自合理的布局规则。直接给所有 Grid 设置全局 RowSpacing/ColumnSpacing 或所有 WrapPanel 重置 Margin，会破坏这些页面的列宽和密度。
6. Mac 原生两处 WrapPanel：数据建模的按钮有右 10、下 8 的显式 Margin；正则的复选框有不同的右 Margin 和上下 3；目前不叠加全局 ItemSpacing，避免两次加距导致换行。

## 修复实现（只改 XCoderMac，不修改上游）

### 通用旧工具留白

新增 `Services/MacLegacySpacing.cs`，在 `Views/MacLegacyToolWindow.axaml.cs` 载入旧窗口内容时启用：
- 对未精调的 GroupBorder 且原外边距为 0~6 的分组，统一底部留白为 **10**。
- 对直接容纳多个控件的纵向 StackPanel 且原 Spacing=0 的分组，设 Spacing=**10**。
- 对 GroupBorder 的直接子 Grid，如果有 2~8 个 Auto/Star 行、原 RowSpacing=0，设 RowSpacing=**7**。
- **不改任何业务绑定或网络命令、不修改所有 Grid 的列距/宽度、不覆盖用户明确配置更大间距的布局。**
- 精调过的 MQTT、API 发现、文件编码、消息调试、加密解密由各自专页适配器维护；这里不二次施加通用规则。

### 加密解密按钮流及右侧分组

新增 `Services/MacSecuritySpacing.cs`，仅对“加密解密”生效：
- 根网格列变为 `296,16,*`，左操作区放宽并和右表单区明确隔开。
- 原 31 个业务命令按钮仍由原上游按钮及 MacSecurityCommandGuard 负责，**不创建新的命令**；按钮宽 **120**、高 **40**、四边 Margin=**5**、内边距 `8,0`、文字居中。WrapPanel 每行两列，按钮水平/垂直可视间隔各 **10**，超出高度可滚动。
- 原文/密码/输出格式/结果四组之间 Grid.RowSpacing=**10**，组 Border.Padding=**12**，圆角 12。
- 原文和密码都去掉多余空占位行，标题/格式选项与输入框使用实际 RowSpacing=**10**，格式 Radio 的原子控件 Margin 归零并设置 ColumnSpacing=10。
- 输出格式横向 StackPanel.Spacing=14，控件原 Margin 清零，避免重复加距。
- 加密结果保留原来的只读、背景、绑定；不变更安全错误处理。

### 其它流控件

`Services/MacMessageDebugLayout.cs` 的“消息调试”选项 WrapPanel 补 ItemSpacing=**6**、LineSpacing=**8**。现有选项与绑定全部保留。
