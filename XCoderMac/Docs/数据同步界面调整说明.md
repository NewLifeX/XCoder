# 数据同步界面布局优化

日期：2026-10-18。XCoder macOS 预览版 0.2.5。

## 问题原因

原始的 `XCoderAv/Views/DataSyncWindow.axaml` 中，源连接按钮 Content 绑定到布尔属性 `IsSourceConnected`，导致源库连接后界面出现无意义的 `True`（断开时可能是 `False`）。

同一行里，源和目标的下拉框被其他按钮占据宽度：源库操作按钮与源库下拉框甚至位于同一个 Grid 列，导致目标数据库下拉框异常狭窄。

## XCoderMac 专用修复

在 `XCoderMac/Views/MacDataSyncWindow.axaml` 和 `.axaml.cs` 中新建 Mac 页面，并在 `MacToolCatalog.cs` 将“数据同步”的页面类型指向 Mac 专用窗口。**不修改 XCoderAv 原有窗口或 ViewModel**，仍复用同一个 `DataSyncViewModel`，连接、读取表、筛选、同步数据业务命令保持原样。

新页面包含：

- 独立的 **源数据库** 与 **目标数据库** 两个卡片分组，每个都有可用宽度自适应的下拉框和明确的“连接/断开”按钮，不再显示 `True`/`False`。
- 目标库仍需源库连接成功后才能选择和连接，原始目标连接筛选行为不变。
- **下拉框首项默认选中**：数据同步界面打开时，源数据库列表不为空就显示第一项；源库连接后目标数据库列表加载完成时，有数据就显示第一项。用户已经选择有效连接时，列表增量更新不会覆盖选择；列表为空则清空过期选择。

- **按钮状态规则**：初始时只能连接源库；源库连接成功后“连接源数据库”禁用、“断开源数据库”启用；目标库连接成功后“连接目标数据库”禁用、“断开目标数据库”启用；分别断开后才允许重新连接。源库断开时目标连接入口同时禁用。所有状态依据上游 `IsSourceConnected`/`IsTargetConnected` 变化，不依赖按钮文字。

- 页面较宽时，两个数据库卡片左右并排，源与目标下拉框各占等宽。
- 页面较窄时（内容区宽度低于 800px），自动上下排列，并支持整体纵向滚动。
- 下方保留数据表选择、全选、反选、仅源表、开始同步及进度/状态，并增加清晰的列头。

## 实际界面和自动化检查

```bash
dotnet build XCoderMac/XCoderMac.csproj -c Debug --no-restore
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-sync-layout
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-tabs
./XCoderMac/package-macos.sh
```

`--smoke-sync-layout` 测试 1540×980、1320×850 和 1000×690 三种主窗口尺寸，验证源/目标卡片、下拉框实际宽度、原有命令文字、连接成功/断开的按钮状态切换及 ViewModel 绑定，不访问真实数据库、不执行同步写入。
