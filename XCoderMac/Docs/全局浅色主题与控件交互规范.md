# XCoder macOS 全局浅色主题与控件交互规范

修复版本：0.2.2；2026-10-18。

## 问题与根因

XCoder 主界面和工具面板明确使用固定浅色背景，但 Avalonia FluentTheme 原来跟随 macOS 系统外观。系统为深色模式时，ComboBox、TextBox、ListBoxItem 及按钮内层模板可能继承暗色背景、白色文字，出现未选中列表不可见、下拉框灰黑底、鼠标悬停文字不清晰等问题。

## 全局处理

- 在 `MacApp.axaml` 显式设置 `RequestedThemeVariant="Light"`，避免同一窗口混合深色控件与浅色页面。
- 在 `XCoderMac/Styles/LightControls.axaml` 集中定义浅色控件规范，应用级使用 `StyleInclude` 引入。
- 所有窗口（主窗口、工具标签内容、独立连接管理窗口、确认弹窗）默认共享这套主题；不用给每个业务窗口重复贴样式。
- 覆盖 Button、TextBox、ComboBox、ComboBoxItem、ListBoxItem、TabItem、MenuItem 以及 TextBlock，明确配置普通、pointerover、selected、pressed、disabled 等状态。
- 业务动作按照语义使用 `Button.primary`、`Button.secondary`、`Button.danger`：
  - primary：蓝底白字，悬停深蓝底白字；
  - secondary：浅蓝底深蓝字，悬停仍保持对比度；
  - danger：淡红底深红字，悬停深红文字。
- 独立连接管理窗口的「保存连接」「测试连接」「删除」等已使用语义类别；原业务命令、绑定及数据库配置规则均未改动。

从当前工程目录运行：

```bash
dotnet build XCoderMac/XCoderMac.csproj -c Debug --no-restore
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-connection-ui
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-modeling-layout

dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-home-layout
```

连接窗口的 `--smoke-connection-ui` 会自动检查：

1. 全局实际主题为 Light。
2. ComboBox 和 TextBox 背景为浅色，文字为深色。
3. ListBoxItem 未选中和选中项都具有深色文字，选中项背景为浅蓝。
4. **真实模拟 pointerover 伪类**，验证两个下拉框、未选中和已选中列表项、测试连接按钮仍是浅底深字。
5. 验证「保存连接」悬停仍是蓝底白字，「删除」仍是淡红底深色文字。
6. 同时回归连接字符串双向解析，并更新 `Docs/软件界面/` 的截图。

本规范目前明确固定浅色主题。后续如果需要随 macOS 切换深色模式，应为全部工具页面设计完整的暗色变量主题，**不能单独移除 Light 设置**，否则旧问题会重现。

## 2026-10-20：所有工具窗口的文本输入框垂直对齐修复

### 问题与原因

- 用户在「API 发现」端口 5500 等输入框发现文本看起来贴近上边，而非视觉上居中；其他工具也有不一致。
- 原应用级 LightControls.axaml 只定义 TextBox 颜色、边框，未给普通单行框统一垂直对齐；部分窗口各自写 Center。
- 旧 XCoderAv 工具普遍将 TextBox.ConfigTextBox 高度设为 26；Mac 宿主又统一加 7,5 的上下 Padding，小高度内的留白挤占正文空间。这也是「API 发现」即使在上游设为 Center 仍显得偏上的原因。

### 本次修改与后续规则

- Styles/LightControls.axaml：全局 TextBox.VerticalContentAlignment=Center；通过 TextBox[AcceptsReturn=true] 例外设为 Top，保留多行输入、日志和 SQL 文本的自然顶部对齐。
- Views/MacLegacyToolWindow.axaml：经旧工具宿主加载的 ConfigTextBox、SmallNumeric 采用 Padding=7,0 和 VerticalContentAlignment=Center，包括 API 发现端口输入，不改上游 XCoderAv。
- Views/MacConnectionManagerWindow.axaml.cs：SmokeTestLightPalette 增加 Name/Port/Password 的 Center 与多行 ConnectionString 的 Top 属性断言。
- **今后新增单行输入框遵循全局 Center；需要多行编辑的 TextBox 明确设置 AcceptsReturn=true，并保持顶部对齐。不要为解决单行问题全局强制多行居中。**
- **所有后续修改必须同轮更新专题规范和项目现状与任务总清单，说明修改位置、测试证据和待办，不允许代码与文档脱节。**
