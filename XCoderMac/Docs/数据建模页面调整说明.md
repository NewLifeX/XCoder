# 数据建模页面响应式布局改造

修改日期：2026-10-18。

## 页面排布

主窗口工具标签下，数据建模界面分为上下两个内容区：

- **上方配置区**：数据库连接（含连接名选择、连接和刷新数据表）与代码生成设置（命名空间、实体连接名、实体基类、输出目录、生成选中表、生成全部表）。
- **页面标题栏**：“打开输出目录”保留在数据建模标题右侧的原始位置，不占用数据库连接卡片空间。
- **下方结构区**：数据表和字段结构左右并排，列表内部独立滚动。
- **页面滚动**：外层 `ScrollViewer` 只启用纵向滚动，避免窗口变窄或变矮时裁切功能区域；不修改 `DataModelingViewModel` 的连接、刷新或代码生成行为。

自适应依据是 **当前嵌入主窗口的页面实际宽度**，不是未显示的业务 `Window` 宽度。扣除页面左右各 25px 边距后：

| 可用内容宽度 | 上方配置区 | 下方结构区 |
| --- | --- | --- |
| ≥870px | 左右并排 | 左右并排 |
| 800~869px | 上下排列 | 左右并排 |
| <800px | 上下排列 | 上下排列 |

页面在 1000×690 的主窗口下可以纵向滚动，全部操作按钮和表结构区域仍可访问。

## 数据库连接配置

最新版的数据库连接管理窗口支持新增、编辑、删除、连接测试和重新加载配置文件。数据建模下拉框通过 XCode.DAL.ConnStrs 使用同一份用户配置。文件保存在 ~/Library/Application Support/Newlife.XCoder/Config/connections.json；编辑后可在配置管理窗口点重新加载。XCode.config 和 Core.config 是组件运行配置，不应在其中放数据库密码。详见 Docs/Newlife.XCoder用户配置与权限规范.md。

## 数据表与字段结构区域高度（2026-10-18）

下方“数据表”和“字段结构”两个列表面板同时从 352px 增加到 **480px**，左右等高。列表内部仍分别滚动；整个数据建模页面也保留纵向滚动，因此缩小窗口时下方内容不会被遮挡。大小窗口自动化检查同时验证两个面板的实际高度及一致性。

## 代码输出目录选择（2026-10-18）

“代码生成设置”中，代码输出目录输入框右侧新增“选择目录 …”按钮，使用 Avalonia StorageProvider 打开 macOS 原生文件夹选择器。用户可继续手动输入目录；选择完成后保存到现有 `DataModelingViewModel.OutputPath`，并自动回填到文本框。取消选择时保留原路径。

工具窗口已被嵌入主窗口标签，故选择器必须通过按钮的 `TopLevel.GetTopLevel(sender)` 找到正在显示的主窗口，避免从未显示的独立 Window 弹出选择器。已有目录作为下次选择时的默认起点。小窗口可滚动布局不变。
