# XCoder Mac 主窗口工作台导航与状态栏

更新时间：2026-10-19；版本 0.2.8。

## 1. 导航布局

- 左侧 **工作台** 保留“所有工具”，去掉原“快捷工具”导航按钮。
- 工具首页中新增可配置的“快捷入口”分区，放在“探索全部工具”上方。初次使用按默认配置显示 8 个入口；点击“管理快捷入口”可以从全部 26 个工具中添加或移除，也可以上移、下移调整顺序。搜索或选择分类时隐藏快捷入口区，只显示匹配的工具列表，不重复显示。
- 左侧工作台下方为“已打开工具（数量）”，复用顶部标签的同一个 `OpenTabs` 集合。单击条目激活该工具，单击条目上的 × 关闭该工具；顶部标签仍可操作。
- 已打开列表在没有标签时隐藏；超过一定数量时内部滚动（最大高 230px），分类区也可滚动，小窗口下不会覆盖底部产品说明。
- 右侧工具区仍保留顶部标签、左右箭头和工具首页按钮，无重复创建相同工具的行为。

## 2. 快捷入口用户配置

- 管理窗口左侧展示全部工具并支持勾选，右侧展示已经选中的快捷入口并支持调整顺序。“恢复默认入口”“取消”“保存设置”各自独立。
- 用户点击“保存设置”后，首页入口直接更新；取消不修改。全部取消勾选是合法偏好，首页显示添加提示。
- 设置保存在 `~/Library/Application Support/Newlife.XCoder/Config/quick-entries.json`，仅用于当前 Mac 用户，写入使用临时文件加原子替换、权限 `0600`，不会出现在签名 APP 包中。
- 重启应用时读取之前保存的名单和顺序；损坏的 JSON 使用默认入口但保留原文件以便恢复；无效/重复工具自动过滤。
- 自动测试 `--smoke-quick-entries` 使用随机临时目录，不碰真实用户偏好，并验证选择、排序、空列表、去重、损坏配置及管理窗口截图。

## 3. 底部统一状态栏

- 工作区底边新增一个固定 32px 的状态栏，不属于任何工具的内部滚动区域。
- 左侧显示“工作台”或当前活动工具名称，右侧显示该工具的 `Status` / `StatusText` 实时状态；当工具切换，立即切换状态数据源。
- 普通 ViewModel 的状态使用 `INotifyPropertyChanged` 订阅；Redis 之类以 `DataContext=this` 把业务对象放在内部 `Vm` 属性的工具，会读取并监听 `Vm.Status`。USB / 声卡硬件信息窗口公开只读设备查询的 `StatusText` 通知。无状态文本但有 `IsConnected` 的网络工具显示实际连接/未连接状态。
- 没有任何可监听的业务状态时显示“已打开 · 等待操作”，不伪造执行结果。无活动工具时返回工作台的“就绪”提示。
- 切换或关闭标签时注销旧订阅，后台标签的状态更新不会覆盖前台状态，也不会在关闭工具后继续触发事件。
- 当前仍保留工具原有的状态显示，不改写上游界面和 ViewModel；底部公共状态栏是跨工具查看的统一入口。

## 4. 自动化验证

从工程根目录运行：

```bash
dotnet build XCoderMac/XCoderMac.csproj -c Debug --no-restore
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-quick-entries
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-home-layout
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-workspace-layout
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-tabs
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-modeling-layout
dotnet run --project XCoderMac/XCoderMac.csproj -c Debug --no-build -- --smoke-sync-layout
```

`--smoke-tabs` 检查 26 工具全部打开/复用/关闭、10 标签滚动、左侧标签切换关闭与数量变化、首页快捷分区、活动及后台 ViewModel 状态，Redis 内层状态，以及硬件信息状态。

`--smoke-workspace-layout` 在真实主窗体下等待两个工具渲染完成，校验左侧可见条目、顶部可见标签、活动页面控件和底部状态，并保存：

- `Docs/软件界面/00-首页.png`
- `Docs/软件界面/00-管理快捷入口.png`
- `Docs/软件界面/00-工作台-已打开工具与统一状态栏.png`

以上仅为 UI/交互/状态绑定回归，真实设备、网络协议及数据库操作仍需要分别做端到端验收。

## 5. 工作台导航清理与悬停样式（0.2.14）

- 移除主窗口顶部重复的“已打开的标签 (N)”按钮，只保留顶部真正的工具标签、左侧“已打开工具 (N)”可点击/可关闭条目以及“工具首页”返回按钮。
- 左侧打开工具的底色由外层 `Border` 负责；普通、选中和悬停时，内层激活 `Button.sidebar-tool-tab` 与 Avalonia Fluent 模板中的 `ContentPresenter#PART_ContentPresenter` 全程透明，不会出现覆盖条目的一块额外色带。
- 左侧列表已直接显示工具名称，不再弹出多余的名称悬停提示气泡；右侧单独的 × 关闭按钮保留提示。
- `--smoke-workspace-layout` 在两个真实工具标签下验证左侧标题、顶部冗余按钮不存在、选中态与悬停模板均无额外背景色；保存 `Docs/软件界面/00-工作台-已打开工具悬停.png`。
