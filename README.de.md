NewLife.XCoder bündelt Codegenerierung, Netzwerk-/API-/Seriell-Debugging, Regex-, Icon- und Krypto-Tools sowie Industrie-Protokoll- und DBC-Viewer.

## Installation

```bash
dotnet add package NewLife.XCoder
```

## Schnellstart

```bash
dotnet run --project XCoder-CLI
```

## Funktionen

- Begleitende CLI-, Debug- und Visualisierungswerkzeuge
- Codegenerierung und stark typisierte APIs mit weniger Boilerplate
- Plattformübergreifend: Windows, Linux, macOS und ARM64/LoongArch64
