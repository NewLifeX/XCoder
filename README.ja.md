NewLife.XCoder はコード生成、ネットワーク／API／シリアルデバッグ、正規表現、アイコン、暗号化などの開発ツールと、産業プロトコル／DBC ビューアを統合します。

## インストール

```bash
dotnet add package NewLife.XCoder
```

## クイックスタート

```bash
dotnet run --project XCoder-CLI
```

## 主な機能

- CLI・デバッグ・可視化ツールを同梱
- コード生成と強く型付けされた API で定型的なコードを削減
- クロスプラットフォーム：Windows / Linux / macOS / ARM64 / LoongArch64
